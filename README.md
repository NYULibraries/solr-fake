# Development history

This codebase was originally developed as [dlts-solr-fake](https://github.com/NYULibraries/dlts-solr-fake),
where as of this writing it still exists.  I later moved from DLTS to AppDev,
and created this new repo by copying `dlts-solr-fake` on September 1, 2026.

This repo was created as a copy instead of a fork to make it a completely 
independent codebase which will evolve (if it evolves at all) based on what 
AppDev testing needs are.
